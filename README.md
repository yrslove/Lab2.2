# Моніторинг температури компонентів

Програма створює синтетичні показники температури процесора, відеокарти та диска і записує їх у CSV-файл. Для кожного виміру зберігаються дата, час, назва комп'ютера, ім'я користувача та UID. Значення накопичуються у динамічному списку ArrayList із попередньої частини лабораторної роботи. Вимірювання справжніх температур обладнання не виконуються.

Для збирання потрібні Linux, GCC та GNU Make. Основна програма використовує статичну бібліотеку `libarraylist.a`. Також передбачено збирання зі спільною бібліотекою `libarraylist.so`.

```sh
make
make shared
make test
make clean
```

Приклад запуску з короткими й довгими опціями:

```sh
make
FILE=temperature.csv ./build/monitor -p -v -t 2 -n 3
./build/monitor_shared --proc --hard --time 1 --number 2
```

Опції `-p` (`--proc`), `-v` (`--video`) та `-h` (`--hard`) вмикають відповідні показники. `-t` (`--time`) задає інтервал у секундах, `-n` (`--number`) — кількість вимірів. Якщо не вибрано жодного компонента, використовуються всі три. Типові значення: інтервал 1 секунда, 5 вимірів та вихідний файл `statistics.csv`. Значення `-t 0` дозволяє запустити збір без пауз для перевірки. Для довідки використовується `--help`.

Файли `include/arraylist.h` і `lib/arraylist.c` перенесено з першої частини роботи без змін. `src/monitor.c` формує записи та зберігає їх, `src/main.c` обробляє параметри і керує циклом. `tests/check.sh` перевіряє запис даних та вибір опцій. Команда `make clean` видаляє скомпільовані файли з каталогу `build`.
